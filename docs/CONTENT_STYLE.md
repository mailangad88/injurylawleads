# Content style: plain, specific, human

Every guide, page, video script and ad follows these rules. They combine the pattern list from [no-ai-slop](https://github.com/petergyang/no-ai-slop) (MIT) with attorney advertising limits. Run `npm run check:copy` before publishing; it flags the patterns a regex can catch.

## Write like this

- **Lead with the answer.** The first two sentences answer the reader's question.
- **Be concrete.** Name the document, the deadline type, the insurance coverage. Skip abstractions.
- **Use active voice and short sentences.** Aim for under 25 words, and break up a sentence that needs two commas to parse.
- **Keep one name per thing.** If it's "the adjuster", don't switch to "the claims rep" and "the insurer's representative" for variety.
- **Write for someone who's hurt and stressed**, often on a phone. Use plain words and short paragraphs.

## Never write these

| Pattern | Looks like | Do instead |
| --- | --- | --- |
| Binary contrast | "It's not X. It's Y." / "That isn't a flaw, it's the system." | State the point directly. |
| Throat-clearing opener | "Here's the thing," "Let me be clear," "The honest answer is" | Start with the answer. |
| Faux insight | "What nobody tells you," "The part everyone misses" | Give the fact. |
| Colon reveal | "The best part: it's free." | Write a normal sentence. |
| Dramatic fragments | "That's it. That's the whole thing." | Fold them into a full sentence. |
| Vague analysis | "highlighting a commitment to excellence" | Say what happened. |
| Importance puffery | "a pivotal moment," "a testament to," "crucial" | Show the consequence instead. |
| Weasel attribution | "experts agree," "studies show" | Name and link the source, or cut the claim. |
| Synonym cycling | adjuster, then rep, then claims handler | Pick one term. |
| Fake-profound ending | "Justice isn't given. It's earned." | End on the next step for the reader. |

## Attorney advertising limits

- No guarantees or predictions of outcomes ("you'll win," "maximum compensation").
- No invented testimonials, verdicts or settlement amounts. Any real ones need the state's required disclaimers.
- Don't call participating lawyers "the best" or "experts" unless a state's rules allow it and it can be shown.
- Label dramatizations and AI-generated people or scenes. Never show an AI person as a real lawyer or client.
- Keep "not a law firm" visible, and don't imply we give legal advice.
